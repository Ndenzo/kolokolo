# Kolokolo

Site web principal de l’agence digitale Kolokolo (Dakar).

## Prérequis

- Node.js 18 ou supérieur

## Installation

```bash
npm install
```

## Démarrage

```bash
npm start
```

Le site est disponible sur [http://localhost:3000](http://localhost:3000).

En développement (rechargement automatique) :

```bash
npm run dev
```
